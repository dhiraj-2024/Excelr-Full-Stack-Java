📘 Full-Stack + Web Basics 
=================================================

1️⃣ What is Full-Stack Development?
-----------------------------------

**Definition:**Full-stack development = working on both:

*   Frontend (UI / client side)
    
*   Backend (server + database)
    

**Remember:**

> Front + Back = Full Stack

2️⃣ Popular Full-Stack Technologies
-----------------------------------

**Frontend:**

*   HTML
    
*   CSS
    
*   JavaScript
    
*   React / Angular
    

**Backend:**

*   Node.js
    
*   Express.js
    
*   Python
    
*   Ruby on Rails
    

**Database:**

*   MySQL
    
*   MongoDB
    
*   PostgreSQL
    

**Memory Tip:**

> Front = UI tools, Back = Server tools

3️⃣ Client-Side vs Server-Side Scripting
----------------------------------------

**Client-Side**

*   Runs in browser
    
*   Faster UI interaction
    
*   Example: JavaScript
    

**Server-Side**

*   Runs on server
    
*   Handles DB + logic
    
*   Example: Node.js, PHP
    

**Memory Tip:**

> Client = Browser | Server = Backend machine

4️⃣ What is RESTful API?
------------------------

**Definition:**API that uses HTTP methods to perform CRUD operations.

**Methods:**

*   GET → Read
    
*   POST → Create
    
*   PUT → Update
    
*   DELETE → Remove
    

**Memory Tip:**

> CRUD = REST actions

5️⃣ What is SPA (Single Page Application)?
------------------------------------------

**Definition:**Loads one HTML page and updates content dynamically.

**Examples:** React, Angular apps

**Benefit:** Faster navigation, no full reload.

**Memory Tip:**

> One Page — Many updates

6️⃣ What is a Database?
-----------------------

**Definition:**Structured storage of data.

**Types:**

*   SQL → MySQL, PostgreSQL
    
*   NoSQL → MongoDB, Firebase
    

**Memory Tip:**

> SQL = Tables | NoSQL = Flexible

7️⃣ Authentication in Full-Stack Apps
-------------------------------------

**Definition:**Verifies user identity.

**Common Method:**

*   Username + Password
    
*   JWT tokens
    

**Memory Tip:**

> Auth = Who are you?

8️⃣ Version Control
-------------------

**Definition:**Tracks code changes and collaboration.

**Tool:** Git**Platform:** GitHub

**Memory Tip:**

> Code history manager

9️⃣ Microservices vs Monolithic
-------------------------------

**Microservices**

*   Many small services
    
*   Independent APIs
    

**Monolithic**

*   One big codebase
    
*   All features together
    

**Memory Tip:**

> Micro = Split | Mono = Single block

🔟 DevOps
---------

**Definition:**Combines Development + Operations.

**Goal:** Faster build + deploy.

**Tools:**

*   Docker
    
*   Jenkins
    

**Memory Tip:**

> Dev + Ops = DevOps

🌐 Web Basics
==============================

1️⃣ What is WWW?
----------------

**Definition:**Collection of linked web pages on the internet.

**Memory Tip:**

> WWW = Web pages network

2️⃣ What is URL?
----------------

**Definition:**Address of a resource on the internet.

**Parts:**

*   Protocol → https
    
*   Domain → example.com
    
*   Path → /about
    

**Memory Tip:**

> URL = Web address

3️⃣ HTTP vs HTTPS
-----------------

**HTTP**

*   Not secure
    
*   No encryption
    

**HTTPS**

*   Secure
    
*   Encrypted
    

**Memory Tip:**

> S = Secure

4️⃣ HTML
--------

**Definition:**Markup language to structure web pages.

**Use:** headings, text, images, links

**Memory Tip:**

> HTML = Structure

5️⃣ CSS
-------

**Definition:**Styles and layout for HTML.

**Use:** colors, fonts, spacing

**Memory Tip:**

> CSS = Design

6️⃣ Client vs Server Scripting (Web)
------------------------------------

**Client:** Runs in browser (JS)**Server:** Runs on server (PHP, Node)

7️⃣ Responsive Web Design
-------------------------

**Definition:**Website adapts to different screen sizes.

**Memory Tip:**

> One site — all devices

8️⃣ Developer Console
---------------------

**Definition:**Browser tool for debugging.

**Use:**

*   Check errors
    
*   Test JS
    
*   Inspect elements
    

**Shortcut:** F12

9️⃣ Cookies
-----------

**Definition:**Small data stored in browser.

**Use:**

*   Login session
    
*   Preferences
    

**Memory Tip:**

> Cookies remember users

🔟 DOM (Document Object Model)
------------------------------

**Definition:**Tree structure of HTML elements.

**Use:** JS can change page dynamically.

**Memory Tip:**

> DOM = Page as objects
