📘 HTML Interview --- Quick Revision Notes
========================================

* * * * *

1️⃣ What is HTML?
-----------------

**Answer:**\
HTML = HyperText Markup Language.\
It is used to create and structure web pages.

**Remember:** HTML = Structure of website

* * * * *

2️⃣ What are the main building blocks of an HTML document?
----------------------------------------------------------

**Answer:**\
HTML documents are made of **elements**.\
Elements are written using **tags**.

**Example:**

`<p>This is a paragraph</p>`

**Remember:** Tag + Content = Element

* * * * *

3️⃣ Difference between HTML and XHTML
-------------------------------------

**HTML**

-   Flexible

-   Small syntax mistakes allowed

**XHTML**

-   Strict rules

-   All tags must be closed

-   Proper nesting required

-   Attributes must have quotes

**Remember:** XHTML = Extra strict HTML

* * * * *

4️⃣ What is `<!DOCTYPE>` in HTML?
---------------------------------

**Answer:**\
It tells the browser which HTML version is used and how to render the page correctly.

**Remember:** DOCTYPE = Browser instruction line

* * * * *

5️⃣ How to create a hyperlink in HTML?
--------------------------------------

**Answer:**\
Use `<a>` tag.

`<a href="https://example.com">Visit</a>`

**Remember:** a = anchor = link

* * * * *

6️⃣ Difference between `<div>` and `<span>`
-------------------------------------------

**`div`**

-   Block element

-   Takes full width

-   Used for big sections

**`span`**

-   Inline element

-   Takes only needed width

-   Used for small text styling

**Remember:**\
div = big box\
span = small wrap

* * * * *

7️⃣ What is `<meta>` tag used for?
----------------------------------

**Answer:**\
Provides page information:

-   charset

-   description

-   SEO data

`<meta charset="UTF-8">`

**Remember:** meta = page info

* * * * *

8️⃣ Difference between `<ol>` and `<ul>`
----------------------------------------

**`ol`**

-   Ordered list

-   Numbers

**`ul`**

-   Unordered list

-   Bullets

**Remember:**\
o = ordered\
u = unordered

* * * * *

9️⃣ What is `<form>` tag?
-------------------------

**Answer:**\
Used to create input forms and send user data to server.

`<form method="POST"></form>`

**Remember:** form = user input sender

* * * * *

🔟 Difference between `<header>`, `<main>`, `<footer>`
------------------------------------------------------

**header** → Top section / intro / navigation\
**main** → Main content\
**footer** → Bottom section / contact / copyright

**Remember:** Top -- Middle -- Bottom

* * * * *

🌐 HTML Basics --- Day 4 Revision
===============================

* * * * *

1️⃣ Why is HTML important?
--------------------------

**Answer:**\
HTML defines the structure and content of web pages.

**Remember:** No HTML = No webpage layout

* * * * *

2️⃣ What is `<html>` tag?
-------------------------

**Answer:**\
Root tag of the whole HTML document. Everything is inside it.

`<html> ... </html>`

**Remember:** html = outer container

* * * * *

3️⃣ What is `<head>` tag?
-------------------------

**Answer:**\
Contains page settings:

-   title

-   meta

-   CSS links

-   scripts

**Remember:** head = page setup area

* * * * *

4️⃣ What does `<title>` tag do?
-------------------------------

**Answer:**\
Sets the page title shown in browser tab.

`<title>My Page</title>`

**Remember:** title = tab name

* * * * *

5️⃣ How to create line break in HTML?
-------------------------------------

**Answer:**\
Use `<br>` tag.

`Line1<br>Line2`

**Remember:** br = break

* * * * *

6️⃣ Explain `<a>` tag
---------------------

**Answer:**\
Creates hyperlinks to:

-   pages

-   files

-   email

`<a href="url">Text</a>`

**Remember:** anchor = link maker

* * * * *

7️⃣ What is `<img>` tag?
------------------------

**Answer:**\
Displays images.

`<img src="img.jpg" alt="desc">`

**Remember:** img = image show

* * * * *

8️⃣ How to create ordered list?
-------------------------------

**Answer:**\
Use `<ol>` with `<li>` items.

`<ol>
  <li>Item</li>
</ol>`

* * * * *

9️⃣ What is `<div>` tag?
------------------------

**Answer:**\
Used to group content and apply styles/layout.

`<div>content</div>`

**Remember:** div = container box

* * * * *

🔟 How to add comments in HTML?
-------------------------------

**Answer:**\
Use comment syntax:

`<!-- comment -->`

**Remember:** invisible note for developers
